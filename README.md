# 👨‍💻 Parth Amin | Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my skills, technical knowledge, certifications, and journey as a developer.

## 🌐 About the Project

This is my personal portfolio website, developed to introduce myself, highlight my technical skills, and provide a platform to connect with me professionally.

The website features a clean, colorful, and responsive design with smooth scrolling animations and interactive navigation.

## ✨ Features

- **Home Section** – Introduction and developer profile.
- **About Me** – Personal introduction and career interests.
- **Skills Section** – Programming languages, coursework, web development skills, and certifications.
- **Contact Section** – Contact form interface to connect with me.
- **Responsive Navigation** – Mobile-friendly navigation menu.
- **Scroll Animations** – Smooth animations using ScrollReveal.
- **Social Media Links** – Connect through social platforms.
